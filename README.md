<h2>🧵 Vintélo – Moda Circular com Tecnologia</h2>
<p>A Vintélo é uma plataforma online focada na venda de roupas de segunda mão, conectando brechós e consumidores que desejam consumir moda de forma consciente, prática e acessível. Nosso objetivo é fortalecer o movimento slow fashion e contribuir com a sustentabilidade no setor têxtil, através de soluções digitais intuitivas e inclusivas.</p>

<h2>📖 Sobre o Projeto</h2>
<p>O projeto foi desenvolvido como uma iniciativa de moda circular, oferecendo uma plataforma para que brechós físicos e online possam vender suas peças com facilidade. Além disso, a plataforma conta com funcionalidades voltadas para o consumidor, como visualização de peças, favoritos, histórico de compras e leitura de artigos sobre moda consciente.</p>

###

<h2>🚀 Funcionalidades</h2>

- Cadastro de clientes, brechós e peças 
- Visualização e pesquisa de peças 
- Carrinho de compras e finalização do pedido
- Blog com artigos sobre moda sustentável
- Favoritos e histórico de compras
- Área para solicitação de reforma de peças
- Painel de gerenciamento para brechós

  ###

<h2>🛠️ Tecnologias Utilizadas</h2>
  
- **Front-end:** HTML, CSS, JavaScript
- **Back-end:** Node.js, Express
- **Banco de Dados:** MySQL
- **Protótipos:** Figma
